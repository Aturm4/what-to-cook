# Что приготовить из того, что есть

Веб-приложение подбирает домашние блюда по продуктам, которые есть под рукой,
и показывает КБЖУ на порцию. Пользователь вводит ингредиенты тегами, нажимает
«Готовить» — и получает карточки блюд, отсортированные по проценту совпадения
продуктов. Клик по карточке разворачивает полный рецепт с граммовками и шагами.

## Стек

- **Vite 6** + **React 18** + **TypeScript**
- CSS Modules + дизайн-токены в CSS-переменных (`src/styles/tokens.css`)
- Google Fonts: Caveat, Kalam, IBM Plex Sans

## Запуск

```bash
npm install
npm run dev      # дев-сервер (http://localhost:5173)
```

## Подбор рецептов

`matchRecipes(ingredients, recipes, options)` в `src/lib/matching.ts` считает,
сколько ключевых ингредиентов рецепта (`recipe.match`) есть у пользователя.
Совпадение токенов — точное после нормализации (lowercase, trim, `ё → е`) либо
по первым трём символам (ловит склонения и множественное число: яйца/яйцо,
помидоры/помидор). Рецепты с хотя бы одним совпадением сортируются по проценту
совпадения, затем по числу совпадений, затем по времени приготовления; берётся
топ-4.

## Данные и бэкенд

База рецептов и логика подбора разделены. Фильтрация зависит только от поля
`match` и не завязана на форму остальных данных, поэтому массив `recipes` можно
заменить ответом от реального API/БД без изменений в UI и логике сопоставления.
